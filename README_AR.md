# GisBi Web لـ Safari

نسخة ويب/PWA بسيطة تعمل على الآيفون عبر Safari: خريطة OpenStreetMap/Leaflet، تحديد الموقع، إضافة نقاط بالضغط، حفظ محلي، بحث، حذف، وتصدير JSON.

## التشغيل بسرعة
الأفضل أن ترفع الملفات على استضافة HTTPS مجانية ثم تفتحها في Safari:
1. ارفع مجلد `GisBiWeb` إلى Netlify Drop / GitHub Pages / Vercel.
2. افتح الرابط في Safari على الآيفون.
3. اسمح بالموقع عند الطلب.
4. للتثبيت كأيقونة: زر المشاركة **Share** ثم **Add to Home Screen**.

## ملاحظات مهمة
- لا تحتاج Mac ولا Xcode.
- هذه ليست نسخة App Store أصلية؛ هي تطبيق ويب/PWA.
- البيانات محفوظة في متصفح Safari على نفس الجهاز فقط. تصدير JSON يحفظ نسخة احتياطية.
- الخرائط تحتاج إنترنت لتحميل البلاطات من OpenStreetMap.

## تعديل سريع
- غيّر مركز الخريطة الافتراضي في `app.js` من السطر:
  `setView([36.8065, 10.1815], 13)`
- غيّر الألوان من `styles.css` داخل `:root`.
